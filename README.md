# dad-joke-cli

A tiny command-line fun-fact generator. No dependencies, no network calls - just a curated set of real trivia across five categories.

## Usage

```bash
python factcli.py                        # prints one random fact
python factcli.py 5                      # prints 5 random facts
python factcli.py --category space       # one fact from a specific category
python factcli.py -c animals 3           # 3 facts from a specific category
python factcli.py --list-categories      # list available categories
```

## Categories

`science`, `history`, `space`, `animals`, `geography`
